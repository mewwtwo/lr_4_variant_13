# ЛР 4, варіант №13

Спільна багатопотокова структура `Fields` з двома цілими полями (`m = 2`). Частоти операцій: поле 0 - read 10%, write 10%; поле 1 - read 50%, write 10%; `string` - 20%.


## Як проводиться вимірювання

Файл з операціями завантажується в пам'ять до запуску таймера. Загальна послідовність ділиться на однакові частини за кількістю потоків, тому для 1, 2 і 3 потоків виконується однакова загальна кількість операцій. Кожен потік отримує власну частину послідовності, а структура `Fields` спільна. Час міряється від створення потоків до `join`; результат усереднюється за вказану кількість запусків. Збірка за замовчуванням Release; в debug-збірці програма попереджає, що час недостовірний.

## Структура

| Файл | Призначення |
|---|---|
| `src/fields.hpp`, `src/fields.cpp` | структура `Fields`, м'ютекси |
| `src/operations.hpp`, `src/operations.cpp` | завантаження й перевірка файлу з операціями |

| `input/mostly_string.txt` | 96% операцій `string` |
| `output/output_results.txt` | результати вимірювань |
| `report.pdf` | звіт |

## Збирання

Потрібні CMake 3.16+ та компілятор C++17: Apple Clang / GCC (macOS, Linux), Visual Studio 2019+ або MinGW-w64 (Windows). Для заміру потрібна збірка Release.

### macOS / Linux

```bash
cmake -S . -B build
cmake --build build
```

### Windows (Visual Studio)

```powershell
cmake -S . -B build
cmake --build build --config Release
```


## Запуск

Усі команди виконуються з папки проєкту, бо шляхи до файлів `input/` відносні. Тестові файли вже є в `input/`; за потреби їх можна згенерувати заново (три файли по 3 000 000 операцій).

| Система | Основна програма | Генератор файлів |
|---|---|---|
| macOS / Linux | `./build/lr_4_variant_13` | `./build/create_input` |
| Windows, Visual Studio | `build\Release\lr_4_variant_13.exe` | `build\Release\create_input.exe` |

Програма без аргументів обробляє файли `input/expected.txt`, `input/even.txt`, `input/mostly_string.txt`. Для кожного виконується 1, 2 і 3 потоки по 10 запусків, виводиться середній час та підсумкова таблиця.

## Формат файлів з операціями

Один рядок - одна операція; порожні рядки ігноруються. Поля нумеруються з 0 (допустимі `0` і `1`).

```
write <номер поля> <значення>
read <номер поля>
string
```

Помилки (невідома команда, номер поля поза діапазоном, відсутнє значення, зайві символи, порожній або відсутній файл) виводяться як `файл:рядок: опис`, код завершення 1.
